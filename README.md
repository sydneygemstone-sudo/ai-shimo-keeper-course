# AI 课 · 毛球驯养手册
## 5 章 × 90 分钟 · 6-8 岁 · 把 AI 知识藏进一场进化冒险

## 这是什么

一门**剧情驱动**的儿童 AI 素养课:第一天教室里出现一颗会发光的蛋,五节课里孩子把它孵化、喂养、教它说话、送它进化、指挥它出战。**课程进度 = 毛球的进化线(蛋→幼体→成体→完全体),AI 知识 = 解锁进化的钥匙**——不学会,剧情推不动。

| 章 | 剧情 | 藏着的真知识 |
|---|------|-------------|
| 1 蛋之章·孵化日 | 通过资格试炼,唤醒蛋 | AI=看例子找规律的程序;传感器;没学过的会认错 |
| 2 幼体章·喂养日 | 毛球饿哭了,它吃"例子" | 训练闭环(Teachable Machine);喂什么学什么 |
| 3 开口章·它说话了 | 第一句话就是错的 | prompt 三段式;幻觉;先想→再问→查一查 |
| 4 进化章·选择之日 | 五张路线卡+一把锁 | agent 四步循环;老板要验收;安全契约 |
| 5 出战章·最终试炼 | 攻打毕业副本 | 完整指挥闭环:下单→监工→终审→改→发布 |

进化路线、天赋、完全体称号与「AI 使魔」产品(`../AI使魔/毛球生成器.html`)**共用一套正式设定**:炎语者/潮音师/风刃使/书之灵/神秘支,五条路线对应五种毕业项目;孩子毕业带走的图鉴卡就是产品世界的"存档"。

## 怎么用

- **备课**:先读 `docs/课程总纲.md`(重点:世界观表+教学法内核表),再过一遍当章 HTML 课件——话术级,含舞台提示,照着能直接开演。
- **文案权威版 = HTML**(2026-08-05 起):lesson-1..5.html 已按 codex 文案 QA(`qa/codex-copy-qa-20260805.md`)完成修订(病句/设定矛盾/事实风险/生动度/全角标点);`curriculum/*.md` 是初稿留档,未同步该轮修订,改文案以 HTML 为准。
- **上课**:主形态是 **HTML 课件**——双击 `index.html`(或起任意静态服务器),投影驱动一切:剧情页、游戏素材、孵化/进化/完全体仪式(点击即演)、徽章墙。**0 实体物料**,只需老师电脑+投影+iPad 若干+白板笔。
- **开课前硬性检查**:① 第 4/5 章的真 agent 演示任务必须提前实测预演;② 毛球终端第 3 章开场剧本要预设。
- **课时变体**:60 分钟版裁剪规则在总纲;孵化/进化/完全体三大仪式永不砍。

## 设计要点(为什么这样做)

- **不是合并版**:与 10 课原版和 v1 讲授版相比,本版没有一节课以"今天我们来学习"开场——每章开场是剧情事件(蛋在发光/毛球饿哭/第一句话是错的),知识是孩子为推动剧情而主动要学的东西。
- **入戏但不当真**:全力利用 6-8 岁"把 AI 当活物"的天性做学习动力,同时每章一次「图鉴真身」锚点+第 4 章情感课,毕业时孩子能自己说出"毛球其实是会学习的电脑程序,没有心"。
- **教学法内核零妥协**:先想后问、查一查、三个不告诉、终审权、"我发现它错了"必填、屏幕纪律、账号合规——10 课版被验证的硬规则全部保留,只换了皮。
