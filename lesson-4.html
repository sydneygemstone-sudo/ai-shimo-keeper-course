选择之日

Evolution Day

毛球睡了一整夜,梦里一会儿喷火、一会儿卷浪。天亮时,枕边多了五张路线卡——梦里的它不光会说,还会自己动手干活(agent 形态)。可进化之门被一把大锁锁死,锁上刻着:「老板不合格,不许进化。」练成老板本领、拿到三把钥匙、带一份契约回家——然后,选择路线,亲手送它进化。

8-20'老板学 ①

会干活的形态 —— agent

师
agent 不是一句咒语什么都能变。配好了工具的 agent,才能按目标做多步工作——能做哪一步,要看它手里有什么工具、老板给了什么权限。拿生日会当例子——
它想做的状态
列出准备清单、写请帖草稿🟢 能计划、能写
查哪家蛋糕店最好吃🟡 要有「查询工具」才行
把请帖发给五位朋友🔴 重要动作——必须先问老板
替你付蛋糕的钱⛔ 没有权限,做不了也不该做
agent 四步循环
① 接目标 → ② 拆任务(plan)→ ③ 一步步做 → ④ 自己检查(check)
师
图鉴警告页:传说第一位驯养师的使魔进化当天,「嗖嗖嗖」寄出了一整城的请帖——主人抢过来一看,自己的秘密,印在每一张的最上面!(全班:完蛋了!)所以铁律两条——
铁律一:重要的动作——发消息、花钱、把东西交出去——
它必须先停下来问老板。

铁律二:它越能干,老板越要检查。
能干的是它,负责的永远是老板。这就是锁上那行字的意思
20-38'老板学 ②

老板门演练(不插电)

每组:1 名老板站在外面 + 3 名 agent 角色(🗂 计划 / 🖍 执行 / 🔍 自检)在"肚子里"。任务:「做一张图书角标志」。老板不抢活,但守住两道门:

🚪 门一 · 计划批准

计划员说完「我打算这样做…」——老板按「同意」或「退回补充」,才能开工。

🚪 门二 · 重要动作批准

执行中要写真名、要"发送"、要"花钱"(剧情设定)——必须停在门口问老板。

自检员主动改一处 → 最后老板终审(留一处明显遗漏等老板抓)。第二轮换任务、换人当老板。

师
老板不替 agent 抢活,但可以在关口说「停、说清楚、再做」。不插手细节,不等于放弃监督。而你们的位置,永远在肚子外面。
孩子从头到尾只当老板,你一人扮 agent 三角色,依次亮出:「我计划这样做…」(他按同意/退回)→「我要写上你的真名了…」(必须停门口等他批)→「我自检发现颜色太浅,改了」→ 终审(你留一处明显遗漏等他抓,并由他决定过不过)。第二轮换新任务,他仍当老板——这一章不体验 agent 角色,立场不能混。

48-62'核心 · 成体预览

看真的 agent 干活(双轨)

📼 步骤实录 · 必做主线

课前保存的完整任务记录(带时间戳):「查三个鲸鱼知识→编成五道问答题→排成一页小报」。逐步回放,全班当监工数三件事:① 拆成了几步?② 有没有可指出的自检动作(列清单/发现问题/改前改后)?③ 成品有没有毛病?

🔴 现场小任务 · 可选

现场只下一个小改动单:「把其中两题改成一年级能读懂,并列出你改了什么。」90 秒无新结果就切回实录。它说「我检查过」不算数——请它指出:检查了哪项、发现了什么、改前改后哪里不同。

师
最后拍板「合格」的是谁?(是我们!)监工卡的最后一栏,永远写着老板的名字。
给孩子 3 枚监工币:看到计划放第 1 枚,看到自检证据放第 2 枚,找到成品问题放第 3 枚。没看到就留在手上并说「我没有看到」——不许因为页面转得快,就替它想象「它一定检查过」。
62-73'开锁仪式

三把钥匙

🗝 ① 它的温柔是模板

使魔说起安慰话,像售货机亮起「祝您愉快」:听着暖暖的,却不是一颗心在里面真的着急。它不坏——只是没有心。真朋友会给你真的拥抱。难过的事,找真人说。

🗝 ② 三只口袋,永远锁紧

🧳 口袋一:身份和地点(真名、学校、住址)
🔑 口袋二:账号秘密(密码、验证码)
🤫 口袋三:私人影像和悄悄话(脸、家里的画面、只跟信任大人说的事)
判断三问:会不会让陌生人找到我?联系我?打开我的东西?——有一个可能,就先不说、问大人。

🗝 ③ 终审权

使魔交上来的任何东西,老板不点头,就不算完成。作品好不好,你先拍板;要不要给别人看、发不发出去,和身边的大人一起拍板。

6 张情境点卡分类练习(能说 / 先问大人 / 不能说),每放一张说理由:「我喜欢恐龙」「我家住在……」「我的画」「妈妈的手机密码」「我今天很难过」「我们学校叫……」。「今天不比快——安全题比的是说得出为什么;不确定就放『先问大人』,也是满分答案。」不吓孩子;有孩子说喜欢跟毛球聊天→「喜欢没问题,就像喜欢一本好看的书;只是难过的事,要留给会真的抱你的人。」

反面 · 30 秒科普 + 明日安排

agent 是 AI 的下一站——不只回答问题,还能替人完成多步骤任务。让孩子从小习惯「我来指挥、我来验收」,比长大后毫无准备地接触 AI 健康得多。若孩子向 AI 倾诉心事,先共情,再引导他把心事也讲给真人听,不用急着没收设备。
