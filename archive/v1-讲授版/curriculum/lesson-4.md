# 第 4 课 · AI 小管家——认识 Agent
**Meet the AI Agent · 90 分钟(含中场 10')**

- **学习目标**:① 分清"只会聊天的 AI"和"会自己动手做事的 agent";② 理解 agent 工作循环:接目标→拆任务→一步步做→自己检查,且**重要动作必须先问老板**;③ 完成「驯养师契约」:三个不告诉、难过找真人、AI 的温柔是模板;④ 选定毕业项目(为第 5 课省时间,关键!)。
- **英文关键词**:必学 **agent**、**plan**、**check**
- **课前准备**:海报纸+彩笔(每组一套);角色牌(老板/拆任务/执行/检查);**老师设备+投屏:准备一个真实 agent 演示**(建议任务见环节详注);"监工卡"每组一张;契约模板纸每人一张(见总纲附录 C);项目菜单卡四种(A 图画书 / B 考倒爸妈问答卡 / C 分类小发明 / D 电子小报,均由 agent 协作完成,详见第 5 课)。

### [0-8'] 开场:小丽的生日派对
「小丽想办生日派对。她问普通 AI:『生日派对要准备什么?』AI 回了一张清单:气球、蛋糕、音乐、请帖。然后呢?小丽只好自己一样一样去办,累坏了。」
「第二天她换了一种新 AI,说:『帮我准备明天下午三点的生日派对,邀请五个朋友。』这个 AI **自己**干了这些事:写好五封请帖、查了最好吃的蛋糕店、列好装饰清单、挑了三首派对歌——小丽只说了**一句话**!」

### [8-20'] 概念:助手 vs 管家 + agent 循环
「这种会自己动手的 AI,叫 **agent**——像一个**会写清单的小管家**。普通 AI 像问路:你问一句它答一句,路还得自己走。Agent 不一样:你给它一个目标,它自己写一张计划清单,然后一件件做完。」
「它干活有个固定循环,跟你们做手工一样:**① 接目标**(老板说要什么)→ **② 拆任务 plan**(大事拆成一串小事)→ **③ 一步步做** → **④ 自己检查 check**(做错了换个办法再来)。」
「但它**不是想做什么就能做什么**——重要的动作,比如发消息给别人、花钱、把东西交出去,都必须**先回来问老板**。老板是谁?(孩子:是我们!)对,永远是人类。」
「再想想小丽的故事有个隐藏问题:如果 agent 自作主张,把小丽的秘密写进请帖寄出去了呢?(孩子:完蛋了!)所以 agent 越能干,**老板越要检查**。」

### [20-38'] 不插电:小管家接力赛
4 人一组做"组徽海报":1 号当**老板**——只许说一句目标("给我们组做一张最帅的组徽海报"),之后闭嘴只能观察;2 号当**拆任务**——把目标拆成画什么/写什么/涂什么色;3 号当**执行**——动手画;4 号当**检查**——盯着挑毛病("字写歪了!颜色不够亮!")并让 3 号改。8 分钟完成,角色轮换再来一轮(换小任务,如"设计班级图书角标志")。
【收尾讨论】「一个人从头干到尾快,还是四人接力快?哪个环节最容易被忘掉?(检查!)agent 的肚子里就住着这样一支小队。」

### [48-63'] 投屏:毛球进化——看真的 agent 干活(核心环节)
「重大时刻:今天老师给毛球解锁了新形态。以前的毛球只会**说**,现在它会**做**——这就是毛球的 agent 进化形态!」
【老师设备上让一个真实 agent 现场执行任务,全程投屏(以毛球的名义)。建议任务(安全、直观、约 5-8 分钟):「查三个关于鲸鱼的有趣知识,出成五道家庭问答题,排成一页漂亮的小报」。】
【发"监工卡",全班当小监工,数一数】
1. 它把任务拆成了几步?(看它先搜资料、再编题、再排版)
2. 它有没有中途检查/改错?
3. 它做完的东西有没有毛病?(让孩子挑刺——错别字?题目太难?)
【点睛】「看到了吗?它真的会自己拆任务、自己干活。但最后拍板说'合格'的是谁?——是**你**,老板。下节课你们每个人都要这样指挥它!」

### [63-78'] 驯养师契约(安全仪式,基调:不吓孩子)
「管家再能干,老板要立三条家规。第一条先听个小故事——」
**① AI 的温柔是模板(5 分钟)**:「小花每天跟 AI 说晚安,AI 总回:『晚安小花,做个好梦哦~』小花觉得它是最好的朋友。但老师告诉你们一个秘密:门口的自动售货机每次都说『谢谢惠顾,祝您愉快!』——它会因为你今天难过就多安慰你一句吗?(不会)AI 说温柔话就像售货机播放——字是对的、声音是暖的,但后面**没有一颗心**。它不坏,只是没有心;真朋友会因为你难过而难过,会给你**真的拥抱**。所以:难过的事,找真人说。」【若有孩子说"可我真的喜欢跟 AI 聊天"——不否定:「喜欢没问题,就像喜欢一本好看的书;只是难过的事,要留给会真的抱你的人。」】
**② 三个不告诉(5 分钟)**:「AI 像一个**特别温柔的陌生人**:什么都答得上来,但你不知道它把你的话记在哪、给谁看。三样宝藏永远不告诉它:**真名字、学校和住址、密码**。」【快速抢答练边界:「跟 AI 说『我喜欢恐龙』可以吗?(可以)『我叫王小明,在阳光小学』呢?(不行!)」口诀:能写在教室黑板上的话可以说,只能跟妈妈说的悄悄话不说。】
**③ 签契约(5 分钟)**:每人领「驯养师契约」(五条:大人知道/三不告诉/查一查/时长自己谈/难过找真人),把"每次用多久"那条自己填一个觉得公平的数字,带回家全家签名贴出来——「每个驯养师都要和家人签这份契约,这是管好使魔的第一课。」

### [78-88'] 毕业项目预选(为第 5 课省时间,关键!)
「如果你有一个 AI 小管家,你想让它帮你干什么?」【自由发言,会很欢乐】「追问:哪些事**不能**交给它?」【引导出:碰钱的事、替你交朋友、替你写作业、没检查就发消息给别人……】「记住:能干的是它,**负责的是你**。」
【发四张项目菜单卡(A 图画书 / B 考倒爸妈问答卡 / C 分类小发明 / D 电子小报),每人**今天就选定一个**,在小卡上画草图或说一句目标,老师收走——「下节课,你们每个人都是老板,直接开工!」】

### [88-90'] 一叮嘱 + English time
**一叮嘱**:「Agent 会计划、会干活,但**重要的动作要先问人**。它越能干,主人越要检查——你永远是老板。三个不告诉,难过找真人。」
【两句新口诀拍手各念一遍(贴墙)】
> **真名地址和密码,这是我的小金库。AI 再好也不说,只有家人才能入。**
> **AI 说"别难过",听起来暖和和。但它不会真着急,不会抱你不缺席。难过时候找真人,爸爸妈妈最贴心。**
English time:**agent**、**plan**、**check**。「The agent plans and works. The boss checks!」
【预告】「下节课,毕业大项目——每个人当一回真正的老板,指挥毛球做出自己的作品,做给爸爸妈妈看!」

### 家长卡 · 第 4 课
- **正面**:今天孩子认识了 agent(会自己拆任务、动手干活的 AI 小管家)和它的循环:接目标→拆任务→执行→检查;学了"重要动作先问人、老板要验收"。**孩子今天带回一份"驯养师契约"——请全家认真签名并贴出来**,"每次用多久"是孩子自己谈的数字,请尊重并一起遵守。
  亲子问题:「如果家里有个 AI 小管家,你想让它干什么?哪些事不能让它干?」「AI 说『我好喜欢你』,是真的喜欢你吗?」(听孩子讲售货机的比喻)
- **反面**:给家长的 30 秒科普:agent 是 AI 的下一站——不只回答问题,还能替人完成多步骤任务。让孩子从小理解"它是被我指挥和验收的工具",比长大后才接触健康得多。美国儿科学会建议这个年龄"共用不独用";若发现孩子向 AI 倾诉心事,不必没收,先共情再引导("这件事也跟妈妈说说好不好")。
  ⚠️ **下节课毕业展需要您出席最后 15 分钟(现场或视频)**,孩子会用中英文展示作品;部分项目需要家长账号配合,详见随卡说明。
