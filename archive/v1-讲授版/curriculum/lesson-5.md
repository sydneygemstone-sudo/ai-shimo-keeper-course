# 第 5 课 · 我的第一个 Agent 项目——毕业展
**My First Agent Project · 90 分钟(含中场 10') · 邀请家长最后 15 分钟到场/连线**

- **学习目标**:① 完整当一次老板/导演:定目标→设计 prompt→指挥 agent→验收挑错→让它修改→展示成果;② 在展示中自然使用双语和三大口诀;③ 把"会检查 AI"内化为荣誉——"我发现它错了"是展示词必填项。
- **英文关键词**:必学 **project**、**director**、**show**
- **课前准备**:第 4 课收存的项目草图;老师设备+投屏(agent 以毛球名义干活,全班轮流指挥);家长账号设备 1-2 台(分组并行用,需大人在场);第 2 课的 Teachable Machine(C 项目用);订书机/打孔绳(装订小书);画纸彩笔;展示词模板大字贴黑板;毕业证书(称号:**Ⅰ期结业·认证小驯养师+小侦探徽章**,注脚印Ⅱ期「Agent 项目工坊」入场资格)。
- **形式说明**:项目在**第 4 课已预选定题**(草图老师收存),本课直接开工冲刺"最小作品"——这是 90 分钟撑得住的唯一办法。**全员都要完成一次"向 agent 下单→监工→验收→改一轮"的指挥闭环**(组内轮流下单,个人部件自己动手做,保留动手感)。**班级超过 8 人**,毕业展改"家长走展"(孩子站在自己作品旁讲给来到面前的家长听),不逐个登台。

| 时间 | 环节 |
|------|------|
| 0-5' | 开场:导演上任,发还草图 |
| 5-35' | 项目冲刺(指挥 agent + 动手做部件) |
| 35-45' | 中场休息(顺便布展) |
| 45-55' | 导演验收:必须挑出 1 个可改进点并改掉 |
| 55-65' | 双语排练 |
| 65-85' | 毕业展 + 颁证(家长到场/连线) |
| 85-90' | 全课程收官 |

### [0-5'] 开场:导演上任
「五节课前,毛球问『什么是 AI』,你们答不上来。今天,你们每个人都是**导演 director**、都是老板——毛球是你的剧组:你说要什么、你检查它干得好不好、你来发布作品。上节课选好的草图,现在发还——开工!」

### [5-35'] 项目冲刺 · 四选一菜单(第 4 课已选定,目标=最小作品)
【组织方式:按项目分组围坐。指挥 agent 的环节分两路并行——老师投屏那台走 A/D 类下单(全班可围观),家长账号设备走 B 类;C 组用 Teachable Machine。**每个孩子至少亲口(语音听写)向 agent 下一单**,哪怕是给同组作品追加一个部件。】
**项目 A · 我和 AI 的图画故事书**(最稳妥,适合多数孩子)
孩子用三段式 prompt 口述故事设定(主角+长什么样+发生什么事)→ 指挥 agent 写出 6 句的小故事 → **导演审稿**:有没有不对的地方?想改哪句?下单让它改 → 每句自己配一幅插图(纸上或 iPad)→ 装订成书,封面写"导演:XXX"。
**项目 B · 考倒爸妈问答卡**(最欢乐)
孩子选最爱主题 → 指挥 agent 出 8 道问答题 → **导演逐题审核**:"这题我查过了吗?太难/太简单?"(用第 3 课三步法筛掉 2-3 题,可下单让它换题)→ 抄成卡片,毕业展现场考家长。
**项目 C · 我的分类小发明**(接第 2 课,最动手)
用 Teachable Machine 训练一个"有用的"分类器:玩具归类员(毛绒 vs 积木)/文具警察(铅笔 vs 橡皮)→ 反复喂例子调到识别可靠 → 展示时现场表演,并讲解"我是怎么训练它的、它什么时候会认错"。【本项目的"agent 下单"环节:让 agent 出一张自己发明的介绍海报文案,孩子验收改错。】
**项目 D · 我的电子小报**(围观感最强)
孩子当老板向 agent 下单(如"做一页关于猫的电子小报,要有三个真知识和一个谜语")→ 用第 4 课监工卡围观它拆任务干活 → **验收挑错**(知识用三步法抽查一条!)→ 下单让它修改一轮 → 发布打印。
【教师巡场口头禅】「导演,检查了吗?」——把第 3/4 课的检查动作变成现场仪式。

### [35-45'] 中场休息(顺便布展)
【孩子休息,老师把作品摆上展示桌/贴墙;>8 人班按走展动线摆位。】

### [45-55'] 导演验收仪式
每人必须给自己的作品挑出 **1 个可改进点**并当场改掉(自己改或再下一单让 agent 改)——「导演,验收了吗?」是本环节口头禅。
【点睛】「在这个教室里,发现 AI 的错不丢人——**是最光荣的事**。挑不出错的导演才要担心!」

### [55-65'] 双语排练
每人按模板准备 30-60 秒展示词(贴黑板):
> 大家好,这是我的 project《____》。(中文讲 2-3 句作品内容)
> I made it with my agent. I am the director!
> 毛球帮我做了____,但是我发现它____(错/不够好)的地方,我让它/我把它改成了____。
> Thank you for watching my show!
【设计意图】"我发现它错了"是展示词**必填项**——把挑错变成最光荣的一句。

### [65-85'] 毕业展 + 颁证
家长到场/连线。**≤8 人**:逐个登台展示;**>8 人**:家长走展(孩子守在作品旁讲给走到面前的家长)。每人展示完,全班一起送一句口诀作为"祝福"(三大口诀轮流用)。
颁发证书:**Ⅰ期结业·认证小驯养师**(小侦探徽章+Ⅱ期入场资格注脚)。
【给家长的一分钟结语,建议照念】「五节课,孩子们学会的不是用 AI 替自己做事,而是:知道它是什么、亲手训练过它、会正确地提问和查证、指挥并验收过一个 agent、知道哪些话不跟它说、知道难过要找真人、知道自己永远是检查和拍板的那个人。这套本领,比任何一个具体工具都活得久。」

### [85-90'] 全课程收官
「毛球的问题都问完了。最后一个问题留给你们:**AI 还会变,你们也会长大——记住你们永远是老板,就什么都不怕。**毕业快乐,小驯养师们!」
「对了——毛球让我捎句话:『出战篇见。』下一期,你们每人选一个**真的项目**,亲自指挥进化版的毛球把它做出来。回家先想:如果毛球什么都肯帮你做,你最想做出什么?」【全班齐背"查一查"口诀,下课】

### 家长卡 · 第 5 课(毕业版)
- **正面**:孩子完成了第一个 agent 项目并双语展示。五课全图:AI 是什么(会学习的机器)→亲手训练 AI→AI 小工具与查一查→认识 agent 与驯养师契约→指挥 agent 完成毕业项目。
  毕业季亲子问题:「这五节课,你最想告诉别人的一件事是什么?」
  ✨ **Ⅱ期·出战篇预告**:结业小驯养师可进入「我的 Agent 项目工坊」——自选一个真项目,亲自指挥 agent 形态的毛球做出来。这两周和孩子聊聊:他最想做出什么?
- **反面**:**毕业后在家怎么继续**(每周一次、每次 15-20 分钟、永远共用):① 周末"AI 小老师"一次(第 3 课姿势);② 每月一个小项目(第 5 课菜单轮着做);③ 三大口诀贴墙上,驯养师契约每学期重签一次——时长条款让孩子重新谈判,他会越谈越成熟。
  ⚠️ 最后的提醒:工具会换代,三个习惯不会过时——**先想后问、查一查、难过找真人。**
