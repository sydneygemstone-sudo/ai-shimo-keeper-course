# AI 课 · 毛球与小驯养师 精编版
## 5 节 × 90 分钟 · 6-8 岁 · 从"AI 是什么"直通"指挥 Agent"

## 这是什么

10 课版 AI 素养课(`~/Claude/AI-Shimo/ai-kids-course/`)的**精编重构版**——不是两两合并,是按「学会基础 → 亲手训练 → 用对工具 → 进阶 agent」的阶梯重新设计的 5 节课:

1. **AI 是什么?——会学习的机器**(基础:看例子找规律、人造非魔法、会犯错)
2. **训练一只你自己的 AI**(AI 训练:Teachable Machine 完整闭环+喂错例子实验)
3. **AI 小工具——让 AI 帮我干活**(应用:prompt 三段式、幻觉与查一查、小老师≠答案机)
4. **AI 小管家——认识 Agent**(进阶:agent 循环、老板要检查、驯养师契约)
5. **我的第一个 Agent 项目·毕业展**(全员当老板指挥 agent,完成下单→监工→验收→发布闭环)

对孩子讲就一句话:**第 1 课认识它 → 第 2 课当它的老师 → 第 3 课让它当你的老师 → 第 4 课收它当管家 → 第 5 课你当老板。**

## 怎么用

- **备课**:先读 `docs/课程总纲.md`(10 分钟),再读当次 `curriculum/lesson-N.md`——脚本到话术级,照着能直接上课。
- **课时变体**:标准 90 分钟(含中场 10');60 分钟变体的裁剪规则在总纲第二节(保底三件套永不砍)。
- **工具**:AutoDraw / Quick Draw!(免登录)、Teachable Machine(老师笔记本网页版+投屏)、毛球终端(自研受控聊天,`~/Claude/AI-Shimo/ai-kids-course/maoqiu-terminal/`)、agent 演示用大人账号投屏。
- **物料**:家长卡内容在每课脚本末尾;契约/口诀/词汇表模板在总纲附录。印刷版排版待做(见下)。
