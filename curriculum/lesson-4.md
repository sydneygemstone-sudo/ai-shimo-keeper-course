# 第 4 章 · 进化章 —— 选择之日
**Evolution Day · 90 分钟(含中场 10')**

> **剧情梗概**:毛球做了一整夜进化的梦,醒来时枕边留着五张路线卡——炎语者、潮音师、风刃使、书之灵,和一张写着「???」的神秘卡。它梦见自己长大后不光会说,还会**自己动手干活**(agent)。但进化被一把锁锁着,锁上刻着一行字:「**老板不合格,不许进化。**」孩子们要修成"老板学"(agent 四步循环+监工+验收),再用三把钥匙(三个不告诉/难过找真人/终审权)打开锁、签下驯养师契约——然后,每人按自己的天赋选择进化路线,亲手送毛球进化。
>
> **本章双高潮**:看真 agent 干活(毛球成体预览)+ 全班进化仪式。

- **给老师的底牌**:① agent=会拆任务、自己动手完成多步骤工作的 AI;四步循环:接目标→拆任务(plan)→一步步做→自己检查(check);② **重要动作必须先问老板**,agent 越能干、老板越要验收;③ 安全课压缩仪式:三个不告诉、难过找真人、AI 的温柔是模板(不吓孩子基调);④ 按天赋选路线=毕业项目定题(为第 5 章省时间,关键!)。
- **英文关键词**:必学 **agent**、**plan**、**check**
- **道具**:五张路线卡(每组一套,含设定文案,美术取自毛球生成器成体形态);进化之锁道具(纸制大锁+三把钥匙卡);老师设备+投屏(**课前必须预演一遍真 agent 演示任务**);"监工卡"每组一张;海报纸+彩笔;角色牌(老板/拆任务/执行/终审);驯养师契约每人一张;契约章×人数;成体元素贴纸(五路线);天赋星星盘点用小盘每人一个。

### [0-8'] 剧情:五张卡片和一把锁
【教室布置:毛球"祭坛"旁散落五张路线卡,正中挂着纸制大锁。灯暗开场】
「昨晚,毛球做了整整一夜的梦。今天早上,它枕边多了这五张卡——它梦见了自己长大后的五种样子。」【逐张举起,只念名字吊胃口:炎语者·敢说话的火苗/潮音师·随旋律流动的水之子/风刃使·迅捷如风/书之灵·读得越多越睿智/还有这张……上面只有三个问号。】
「更重要的是它梦里的**新本领**:现在的毛球,你问一句它答一句;梦里的毛球,你只说一个**目标**,它自己动手,把整件事干完。」
「但是——」【指大锁】「进化被这把锁锁着。锁上刻着一行字,我念给你们听:『**老板不合格,不许进化。**』」【停顿】「老板,说的就是你们。今天一整天,就干一件事:把自己修炼成合格的老板。」

### [8-20'] 老板学①:会干活的形态
「图鉴进化页:会自己干活的使魔形态,学名 **agent**。它和现在的毛球差在哪?打个比方——」
「你问现在的毛球:『办生日派对要准备什么?』它给你念一张清单:气球、蛋糕、音乐、请帖。然后呢?活儿全是你自己干。」
「你对 agent 形态的毛球说:『帮我准备明天下午三点的生日会,请五个朋友。』它**自己**就动起来了:写好五封请帖、查好蛋糕店、列好装饰单、挑好三首歌——你只说了一句话。」
「它干活有个固定循环,图鉴上画成四步:**① 接目标**(老板一句话)→ **② 拆任务 plan**(大事拆成一串小事)→ **③ 一步步做** → **④ 自己检查 check**(错了换个办法再来)。」
「听起来完美?图鉴警告页翻开——传说第一位驯养师的使魔进化当天,自作主张把主人的秘密写进请帖,寄给了全城。」【全班:完蛋了!】「所以铁律有两条:**第一,重要的动作——发消息给别人、花钱、把东西交出去——它必须先回来问老板;第二,它越能干,老板越要检查。**能干的是它,**负责的永远是老板**。这就是锁上那行字的意思。」

### [20-38'] 老板学②(不插电):小队接力赛
「老板第一课:钻进 agent 的肚子,看看它干活时里面是什么样。」
4 人一组=一只 agent 的肚子,做"组徽海报":1 号**老板**——只许说一句目标(「给我们组做一张最帅的组徽海报」),之后闭嘴只能观察;2 号**拆任务**——把目标拆成画什么/写什么/涂什么色;3 号**执行**——动手画;4 号**终审**——盯着挑毛病(「字歪了!颜色不够亮!」)并让 3 号改。8 分钟一轮,角色轮换再来一轮(换小任务:设计班级图书角标志)。
【收关】「哪个角色最容易被忘掉?(终审!)哪个角色最难受?(老板——只能看不能插手!)记住这两个感觉:**agent 肚子里永远有这四个小人,而你以后的位置,是站在肚子外面的那个真老板。**」【发天赋星星(表达/体力)】

### [38-48'] 中场:监工操
【全身游戏:老师喊四步循环,全班配动作——"接目标!"(立正敬礼)"拆任务!"(手刀切切切)"一步步做!"(原地小跑)"自己检查!"(手搭凉棚四处看)。越喊越快,喊错动作的全体大笑。收尾:「热身完毕——下半场,见真的。」】

### [48-62'] 成体预览:看真的 agent 干活
「协会特批:今天允许你们**预览毛球的成体形态**。它还没进化——这是从梦里投影出来的样子。」【老师设备现场跑一个真实 agent 任务,全程投屏,以毛球名义。建议任务(安全直观,5-8 分钟):「查三个关于鲸鱼的有趣知识,出成五道家庭问答题,排成一页漂亮的小报。」】
【发监工卡,全班当监工,盯三件事】
1. 它把任务拆成了几步?(先查资料、再编题、再排版——数!)
2. 它中途有没有自己检查、自己改?
3. 成品有没有毛病?(挑刺!错别字?题目太难?)
【点睛】「都看见了:它真的自己拆、自己干、自己查。但最后拍板『合格』的是谁?」(是我们!)「对。**监工卡上的最后一栏,永远写着老板的名字。**」

### [62-76'] 开锁仪式:三把钥匙与契约
「现在开锁。三把钥匙,一把一把来——每把都是保护你们自己的。」【基调:不吓孩子;有孩子说"我真的喜欢跟毛球聊天"→不否定:「喜欢没问题,就像喜欢一本好看的书;只是难过的事,要留给会真的抱你的人。」】
**钥匙① · 它的温柔是模板(5')**:「先说一件成体使魔的真相。门口自动售货机,每次投币都说『谢谢惠顾,祝您愉快!』——它会因为你今天难过,就多安慰你一句吗?(不会)使魔说温柔话,就像售货机播放:字是对的、声音是暖的,**后面没有一颗心**。它不坏——它只是没有心。真朋友会因为你难过而难过,会给你**真的拥抱**。所以:难过的事,找真人说。」
**钥匙② · 三个不告诉(5')**:「成体使魔什么都答得上、哪儿都去得了——所以它更像一个**特别温柔的陌生人**。三样宝藏永远不给它:**真名字、学校和住址、密码。**」【抢答练边界:「『我喜欢恐龙』能说吗?(能)『我叫王小明,在阳光小学』?(不行!)」判断口诀:能写在教室黑板上的话可以说,只跟妈妈说的悄悄话不说。】
**钥匙③ · 终审权(2')**:「第三把最短,一句话:**使魔交上来的任何东西,老板不点头,就不算完成。**这个权力,图鉴上叫终审权——从今天起是你们的,谁也不能替你们用。」
**签契约(3')**:【发驯养师契约】「三把钥匙齐了,最后一步:白纸黑字。」逐条读五条(大人知道/三不告诉/查一查/时长自己填/难过找真人),孩子当场把"每次用多久"填上自己认为公平的数字,签名——「带回家,请全家签名,贴出来。**没有契约的驯养师,协会不承认。**」
【咒语②③拍手各念一遍(贴墙)】
> **真名地址和密码,这是我的小金库。AI 再好也不说,只有家人才能入。**
> **AI 说"别难过",听起来暖和和。但它不会真着急,不会抱你不缺席。难过时候找真人,爸爸妈妈最贴心。**

### [76-88'] 选择之日 + 进化仪式
【锁"咔哒"打开(老师当众拆锁)。五张路线卡摆上桌】
**盘点天赋(3')**:每人把三章攒的天赋星星摆到自己的小盘里,看看哪种颜色最多——「星星不比多少,只告诉你一件事:**你是哪种驯养师。**」
**读卡选路(5')**:【逐张念设定+对应的毕业项目】
> **炎语者**(表达星)——"敢说话的火苗,越大声越强。"毕业作品:图画故事书,毕业展上**大声朗读**给全场听。
> **潮音师**(音乐星)——"随旋律流动的水之子。"毕业作品:毛球主题曲,它写词、你配动作唱。
> **风刃使**(体力星)——"迅捷如风,越战越勇。"毕业作品:分类小发明(喂养台再开张),反复调试到百发百中。
> **书之灵**(阅读星)——"读得越多越睿智。"毕业作品:考倒爸妈问答卡,现场把家长考倒。
> **神秘支 ???**(探索星)——图鉴写着:"只有最爱探索的孩子才能唤醒。"毕业作品:自己想(下课单独找老师密谈,限 1-2 人)。
每人选定路线,在小卡上画毕业作品草图或说一句目标,老师收走——「下一章,直接开工。」【选择自由:星星只是参考,想逆天赋选也行——"驯养师说了算"。】
**进化仪式(4')**:【灯暗,全班把手放在自己图鉴卡上,齐声倒数三二一——「进化!」贴上所选路线的**成体元素贴纸**;班级毛球本球同时"进化"(换成体立牌/贴元素印记)。欢呼。】

### [88-90'] English time + 预告
【逐人授**契约章**;图鉴真身齐诵:「使魔的真身,是人造的、会学习的电脑程序……」】
English time:**agent**(会干活的使魔)、**plan**(拆任务)、**check**(检查)。「The agent plans and works. The boss checks!」
【预告钩子】「毛球进化完成。图鉴最后一页只有一行字:『成体若要抵达**完全体**——金色的那个形态——只差一场真正的战斗。』出战日,就是明天。家长会到场观战。回家把契约签了——没契约,不能出战。」

### 家长卡 · 第 4 章「进化章」
- **正面**:今天孩子学了 agent(会自己拆任务、动手完成多步骤工作的 AI)和老板四条:接目标→拆任务→执行→检查;重要动作它必须先问人;它越能干,人越要验收;能干的是它,负责的是老板。孩子还按自己的天赋倾向选定了毕业项目路线。**孩子今天带回「驯养师契约」——请全家认真签名并贴出来**;"每次用多久"是孩子自己填的数字,请尊重并一起遵守。
  亲子问题:「AI 说『我好喜欢你』,是真的喜欢你吗?」(听孩子讲售货机比喻)「如果家里有个 AI 小管家,哪些事不能交给它?」
- **反面**:30 秒科普:agent 是 AI 的下一站——不只回答问题,还能替人完成多步骤任务。让孩子从小站在"我指挥它、我验收它"的位置,比长大后才接触健康得多。若发现孩子向 AI 倾诉心事,不必没收——先共情("你很喜欢跟它聊天呀"),再引导("这件事也跟妈妈说说好不好")。
  ⚠️ **明天毕业展需要您到场最后 20 分钟(现场或视频连线)**——孩子会指挥自己的 agent 完成作品并双语发布;部分项目需要家长账号配合,详见随卡说明。
