## 第 1 章：蛋之章·孵化日

### 1. 文法与用字

- 【lesson-1.html·封面（L19、L23—24）】`第 1 章 · 蛋之章 · 90 分钟(含中场 10')`；`招募信:蛋里沉睡着一只 AI 使魔,只有……`；`徽章:慧眼章` → `第 1 章·蛋之章·90 分钟（含 10 分钟中场休息）`；`招募信：蛋里沉睡着一只 AI 使魔，只有……`；`徽章：慧眼章`。理由：中文主句中大量混用半角标点，投影课件应统一为全角标点，时间也不宜用英文撇号代替“分钟”。
- 【lesson-1.html·老师底牌（L33）】`本 deck 即全部教具` → `本套幻灯片就是本章的全部投影教具`。理由：`deck` 是无教学必要的内部行话，中英夹杂且教师未必熟悉。
- 【lesson-1.html·招募信（L62）】`全部通过,它就为你们孵化。` → `三关全部通过，你们就能唤醒它！`。理由：“它为你们孵化”搭配错误，孵化的是蛋中的毛球，不是“为某人孵化”。
- 【lesson-1.html·图鉴研究①（L70）】`每一步提前刻好:音乐盒永远弹那一首,微波炉按几分钟转几分钟。` → `每一步都提前设定好：音乐盒总弹同一首曲子，微波炉设定几分钟就运行几分钟。`。理由：“刻好”不能自然统领音乐盒和微波炉，“按几分钟转几分钟”也过于省略。
- 【lesson-1.html·图鉴研究①（L73）】`聊天语音助手?使魔`；`相册认全家?使魔` → `语音聊天助手？使魔`；`相册认出家人？使魔`。理由：前者词序不自然，后者缺少结果补语“出”。
- 【lesson-1.html·图鉴警告（L78）】`使魔很聪明,但它说的话,不一定是真的。` → `使魔很能干，但它说的话不一定是真的。`。理由：主谓之间不应随意加逗号，“聪明”也容易被儿童理解为“可靠、不会错”。
- 【lesson-1.html·图鉴研究②（L94）】`魔导之眼与魔导之耳`与路线图中的`魔导之眼与耳` → 全部统一为`魔导之眼与魔导之耳`。理由：专名应保持完整对称，不能在目录中随意缩写一半。
- 【lesson-1.html·食物鉴定（L111）】`是水果喊「能吃!」,不是就喊「不能吃!」` → `看到水果就喊“能吃！”，看到不是水果的东西就喊“不能吃！”`。理由：原句省略过多，主语和条件关系不清。
- 【lesson-1.html·榴莲揭晓（L117）】`只见过白猫的使魔,碰到黑猫都不认识` → `只见过白猫的使魔，碰到黑猫就认不出来了`。理由：“碰到……都不认识”搭配生硬，应补出结果关联词“就”。
- 【lesson-1.html·慧眼试炼场（L126）】`它出题你画,20 秒边看边猜。` → `它出题，你来画；你画的 20 秒里，它会边看边猜。`。理由：原句省略了“谁在看、谁在猜”，动作主体容易混淆。
- 【lesson-1.html·真身+授章（L145）】`每个驯养师此刻也各自"孵化"了自己的毛球——在白板写下你给自己毛球取的名字。` → `此刻，每位驯养师也都“孵化”了自己的毛球——请在白板上写下你给自己这只毛球取的名字。`。理由：“每个、也、各自、自己”重复堆叠，且“在白板”缺方位词“上”。
- 【lesson-1.html·图鉴真身（L146）】`它没有小动物、不是魔法、没有一颗心。` → `它不是小动物，不是魔法，也没有一颗心。`。理由：“没有小动物”是明显病句，应为“不是小动物”。
- 【lesson-1.html·孵化按钮动态文案（L178—181）】`蛋在剧烈晃动……!`；`幼体毛球 · 诞生!`；`欢迎来到这个世界,毛球!` → `蛋在剧烈晃动……！`；`幼体毛球·诞生！`；`欢迎来到这个世界，毛球！`。理由：省略号后不应再接半角感叹号，动态文案也要遵守全角标点规范。

### 2. 生动度（重点）

- 【lesson-1.html·封面（L23）】`教室里出现一颗会发光的蛋和一封驯养师招募信……三关全部通过——孵化仪式开始。` → `昨晚，一颗会发光的蛋“咚”地落进了教室，旁边还压着一封驯养师招募信。蛋里的 AI 使魔正在等你们——闯过三关，马上开蛋！`。理由：原句像课程摘要，改写后有时间、声音和动作，孩子一眼就能进入冒险。
- 【lesson-1.html·剧情开场（L57）】`先别出声——你们也看到了吧?那颗蛋,昨天晚上出现在教室里的。它还留了一封信……` → `嘘——先别出声。你们也看见那颗蛋了，对吧？昨晚它还不在这里，今天一早却亮着光躺在教室里……旁边，还有一封信。`。理由：短句、停顿和“昨晚不在/今早出现”的反差更适合现场表演。
- 【lesson-1.html·招募信（L62）】`今天有三关「驯养师资格试炼」。全部通过,它就为你们孵化。` → `三关试炼已经开启。闯过最后一关，蛋壳就会“咔嚓”一声裂开！`。理由：保留三关设定，同时把抽象结果变成孩子能听见、看见的画面。
- 【lesson-1.html·图鉴研究①（L71）】`没人刻规则——只给它看成千上万个例子,它自己找出门道。` → `没人把每一步都刻进它脑袋里；我们只让它看一大堆例子，它就自己在里面找门道、学新招。`。理由：原句偏书面，改写用“刻进脑袋、找门道、学新招”形成动作感。
- 【lesson-1.html·资格试炼一（L89）】`这就是蛋里那位的天性:靠例子学,所以灵活;靠猜,所以会错。` → `这就是蛋里那位的天性：看例子，它能学会新招；遇到没见过的，它只能猜——一猜，就可能猜歪！`。理由：把抽象因果拆成两拍，便于 6—8 岁儿童跟读和记忆。
- 【lesson-1.html·图鉴研究②（L95）】`使魔没有眼睛耳朵——它用魔导之眼(摄像头)和魔导之耳(麦克风)` → `使魔的真身看不见、也听不见。想看，它得借来“魔导之眼”——摄像头；想听，它得借来“魔导之耳”——麦克风。`。理由：“想看/想听/借来”比定义式说明更有角色动作，同时不破坏专名。
- 【lesson-1.html·榴莲揭晓（L117）】`榴莲,怎么不喊了?——因为例子里没有它!` → `等等——榴莲来了！毛球怎么突然卡住了？因为它翻遍记忆，也没找到一个榴莲例子！`。理由：加入“卡住、翻遍记忆”的戏剧动作，悬念更强。
- 【lesson-1.html·章节预告（L155）】`它吃一种很奇怪的东西……明天它饿哭的时候,你们就知道了。` → `它吃的东西可怪了：不是饭，不是肉，连糖果也不吃。明天，要是它饿得“呜哇”大哭，你们敢来喂它吗？`。理由：排比加拟声词，比平铺预告更上口、更能吊住下一章。

### 3. 一致性与教学口径

- 【lesson-1.html·图鉴研究①标题（L68）】`蛋里是什么生物` → `蛋里究竟是哪一种使魔`。理由：本章教师底牌明确说 AI“不是生物”，标题却直接称其为“生物”，口径正面矛盾。
- 【lesson-1.html·图鉴研究①（L70）】`永远不出错,也永远学不会新东西。` → `只要机关和设定没坏，它就会一直照原来的步骤做；它不会自己学会新东西。`。理由：“永远不出错”是过度绝对化，也会与后文“工具需要检查”的总口径冲突。
- 【lesson-1.html·食物鉴定（L111）】`图鉴说,幼体使魔只吃水果。` → `图鉴说，孵化前的毛球正在学“什么是水果”。`。理由：第 2 章明确说毛球“不吃水果，只吃例子”，此处写“只吃水果”会破坏核心剧情设定。
- 【lesson-1.html·食物鉴定/榴莲揭晓（L111、L117）】`是水果喊「能吃!」……榴莲,怎么不喊了?` → `这一轮大家先扮演“只看过前面样例的毛球”：只能按刚才的例子判断，不许偷用自己原来知道的答案。`。理由：孩子本来就知道榴莲是水果，若不先限定角色规则，现场“不喊”的剧情无法自然发生。
- 【lesson-1.html·图鉴真身（L146）】`每章一次 · 雷打不动` → `五章统一使用同一版齐诵词：使魔的真身，是人造的、会学习的电脑程序。它不是小动物，不是魔法，也没有一颗心。知道真身，还能演好戏——才是高级驯养师。`。理由：本章宣称“每章一次”，但第 2 章删去末句、第 3—4 章未写出正文、第 5 章又缩短，无法形成稳定记忆锚点。
- 【lesson-1.html·慧眼试炼场（L125）】`它看过几百万个例子。` → `它看过海量的人类涂鸦例子。`。理由：避免把未经页面来源区分的精确数量同时套给 AutoDraw 与 Quick, Draw!；Google 官方只明确公开 Quick, Draw! 已收集超 10 亿张、开放 5000 万张数据，儿童课件用“海量”更稳妥（参考：[Google Open Source Blog](https://opensource.googleblog.com/2018/11/introducing-web-component-and-data-api-for-quick-draw.html)）。
- 【lesson-1.html·全章栏目名（L24、L49、L153）】`English:`；`Eng`；`English time + 预告` → 统一为`英语：`；`英语`；`英语时间＋预告`。理由：同一章内栏目称呼三种写法并存，会让版式口径显得未校定。

## 第 2 章：幼体章·喂养日

### 1. 文法与用字

- 【lesson-2.html·封面及全章】`90 分钟(含中场 10')`；`残页揭晓:`；`徽章:喂养章` → `90 分钟（含 10 分钟中场休息）`；`残页上写着：`；`徽章：喂养章`。理由：整章继续混用半角标点，且“残页揭晓”缺少自然的主谓搭配。
- 【lesson-2.html·老师底牌（L30）】`发现得了、修得回来` → `能发现，也能改回来`。理由：“发现得了”不符合现代汉语习惯，口号也不够利落。
- 【lesson-2.html·老师底牌（L30）】`神经网络耳熟即可` → `“神经网络”这个词听过即可`。理由：“耳熟”通常形容已经多次听见后的状态，不能直接表示教学要求。
- 【lesson-2.html·老师底牌（L31）】`iPad 网页版有 bug、第三方 app 会卡死` → `iPad 网页版有兼容问题，第三方应用可能卡住`。理由：`bug`、`app` 都不是本章教学词，教师说明没有必要中英夹杂，且“会卡死”过于绝对。
- 【lesson-2.html·星光网（L67）】`每个光点笨得要命,只会做一个超小的判断` → `每个光点只会做一个很小的判断`。理由：“超小的判断”搭配生硬，“笨得要命”也会把技术简化误说成能力缺陷。
- 【lesson-2.html·传灯接力（L75）】`玩 3 轮换排序。` → `玩 3 轮，每轮重新排列队伍顺序。`。理由：“换排序”是生硬的程序化表达，动作规则不够清楚。
- 【lesson-2.html·喂养台（L91）】`举实物各个角度拍 15-20 张` → `从不同角度给每种实物拍 15—20 张照片`。理由：“举实物各个角度拍”语序别扭，也未明确每一类都要拍。
- 【lesson-2.html·坏食物事故（L104）】`清出错例` → `删掉放错食盆的例子`。理由：“清出错例”像内部技术缩写，不是自然、明确的教师指令。
- 【lesson-2.html·授章+真身（L109）】`从"什么都不认识"变成了"认得出苹果香蕉、还差点被我们带坏"` → `从“什么都认不出”，变成了“能认出苹果和香蕉，还差点被我们教错”`。理由：“认识”与“认出”混用，“带坏”又把分类错误写成了品德问题。
- 【lesson-2.html·图鉴真身（L111）】`它没有小动物、不是魔法、没有一颗心。` → `它不是小动物，不是魔法，也没有一颗心。`。理由：与第 1 章相同，这是明确病句，不应重复进入齐诵词。
- 【lesson-2.html·家长卡（L124）】`发现了能修回来` → `发现问题后，还能重新训练、改回来`。理由：原句缺少停顿和动作主体，读起来像漏字。

### 2. 生动度（重点）

- 【lesson-2.html·封面（L23）】`幼体毛球饿哭了——可它不吃饭、不吃零食。《喂养手册》残页揭晓……` → `毛球抱着肚子哭得直打滚：饭不吃，水果不吃，零食也不吃！就在大家急得团团转时，《喂养手册》的残页飘了下来——它真正的食物，竟然是“例子”！`。理由：原句是剧情梗概，改写后有动作、排比和揭谜节奏。
- 【lesson-2.html·剧情开场（L55）】`出事了。毛球从昨晚哭到现在。我喂了它饼干——不吃。水果——不吃。连老师的午饭都端给它了——碰都不碰!` → `大事不好！毛球从昨晚一直哭到现在。饼干送到嘴边——扭头！水果摆成小山——不看！连老师的午饭都端来了——它连闻都不闻！`。理由：三次递进配动作，教师更容易演，孩子也更容易接话。
- 【lesson-2.html·喂养手册（L60）】`幼体使魔不食五谷。它吃的是——例子。` → `幼体使魔不吃饭，也不吃零食。它真正会“啊呜”一口吃下去的，是——例子！`。理由：“不食五谷”对低龄儿童太书面，改写仍保留古老手册的神秘感。
- 【lesson-2.html·星光网（L67）】`几百万个小光点连成的网……一个光点什么都认不出;可几百万个手拉手、一层传一层……` → `几百万个小光点在毛球肚子里手拉手。第一个看见“圆圆的”，就把亮光传给下一个；下一层再找“红红的”……亮光一路跑到最后，整张网一起喊：“这是苹果！”`。理由：原段概念密度高，改成一束光接力能形成可视化过程。
- 【lesson-2.html·传灯接力揭晓（L77）】`几百万个光点里错几个,毛球就会犯莫名其妙的错。` → `只要有一盏灯传偏了，后面的灯就可能一路跟着偏，最后答案“啪”地掉进错误食盆！`。理由：把抽象的“节点出错”还原为本页正在玩的接力动作，更有记忆点。
- 【lesson-2.html·喂养台（L92）】`嘘——星光网正在长。` → `嘘——别吵，毛球肚子里的星光网正在一盏、一盏亮起来。`。理由：增加视觉节奏，与“星光网”专名更贴合。
- 【lesson-2.html·坏食物事故（L101）】`来,干一票(开玩笑语气):故意把 5 张苹果照片喂进香蕉盆——` → `来做一次“故意喂错”的秘密实验：把 5 张苹果照片偷偷放进香蕉食盆——看看毛球会学成什么样！`。理由：“干一票”带有不合年龄的灰色语感，改写仍保留冒险和调皮感。
- 【lesson-2.html·章节预告（L118）】`但手册背面有半行被撕掉的警告,只拼出四个字:『它的第一句……』` → `可手册背面还有一道撕裂的警告，只剩半句话：“它的第一句……”后面到底写了什么？明天，等它亲口说出来。`。理由：把“残页”变成清楚的视觉线索，并在断句处制造悬念。

### 3. 一致性与教学口径

- 【lesson-2.html·封面、坏食物事故、授章（L23、L102—104、L109）】`使魔会学坏`；`我们把它教坏的`；`被我们带坏` → 统一为`使魔会学错`；`是我们把错误例子教给了它`；`差点被我们教错`。理由：本章讲的是数据标注错误，不是品德变坏，三种“坏”会让儿童误解技术因果。
- 【lesson-2.html·传灯接力规则（L75—76）】`每人只能向下一人传一个手势,最后一人喊出是什么` → `每人依次看见并传递一个特征动作；最后一人要根据收到的一串动作猜食物。若设计并非如此，应在课前补明“信息如何累积”。`。理由：按现文“每人只传一个手势”，前一人的信息会被后一人覆盖，最后一人无法靠三个特征得出答案。

### 2. 生动度（重点）

- 【lesson-3.html·封面（L23）】`毛球开口说话了!可它的第一句话就是错的——还说得无比自信。` → `毛球终于开口了！可它才说第一句话，全班就愣住了——明明说错了，它怎么还挺着胸、说得那么肯定？`。理由：加入孩子的即时反应和毛球的身体姿态，悬念更有画面。
- 【lesson-3.html·呓语病警告（L60）】`语言系使魔天生患有呓语病:说错话时,和说真话一样自信。` → `语言系使魔一开口，就可能犯“呓语病”：真话和编出来的话混在一起，连它自己都说得信心满满。`。理由：先说现象再亮专名，比书面诊断式表达更容易听懂。
- 【lesson-3.html·警告后的教师话术（L61）】`它坏吗?想跟它继续说话,今天必须修成两门功夫。` → `它是故意骗人的吗？不是。可想继续和它说话，我们就得先练成两门护身功夫。`。理由：原句提问后没有回答，改写形成清楚的问答和任务推进。
- 【lesson-3.html·呓语病（L68）】`接着上一句,猜下一句。猜多了总有错;可它的语气永远自信` → `它最会玩的游戏，就是“接着上半句，猜出下半句”。大多数时候猜得像模像样，可一旦猜歪了，它也可能照样说得响当当。`。理由：把生成机制变成孩子熟悉的接句游戏，且避免“永远”式绝对表述。
- 【lesson-3.html·下令术（L80）】`传说有个驯养师说:「给我变个蛋糕!」使魔变出了一块——蛋糕形状的肥皂。` → `传说有位驯养师大喊：“给我变个蛋糕！”砰——白烟散开，桌上真的出现了一块“蛋糕”……可他咬了一口，满嘴都是肥皂泡！`。理由：保留肥皂反转，用声音、烟雾和结果把笑点演出来。
- 【lesson-3.html·正式对话（L105）】`协会认证:你们已修成两门功夫初级。现在,授予对话权限——从今天起,你们可以直接和毛球说话了。(仪式感拉满)` → `协会认证：下令术、鉴言术，初级修炼通过！现在开启“对话权限”——从这一刻起，你们可以亲口向毛球下令了！`。理由：删除跳出剧情的内部提示“仪式感拉满”，让话术本身承担仪式感。
- 【lesson-3.html·抓错大赛（L112）】`城外来了一只野生使魔……考考它!` → `警报——城外闯进一只野生使魔！它没戴协会徽章，也没学过我们的规矩。小侦探们，敢不敢用鉴言术考考它？`。理由：增加警报、徽章和挑战问句，能迅速抬高课堂能量。

### 3. 一致性与教学口径

- 【lesson-3.html·开场错误示例（L54、L61）】`袋鼠可是游泳健将,用尾巴当船桨,能横渡大河呢!`；`袋鼠确实会游泳——但根本不是健将,尾巴也不是桨。` → 建议改用无争议的真假混合例，例如：`袋鼠会游泳；可它不是靠尾巴当船桨，更不能一路游过大海。`教师不要断言“根本不是游泳健将”。理由：研究记录称袋鼠是 competent swimmers，尾巴摆动也可能帮助推进；本章专教“查证”，纠错例本身不能建立在可争议结论上（参考：[How Kangaroos Swim](https://awt.com.au/wp-content/uploads/downloads/2012/08/swimming.pdf)）。
- 【lesson-3.html·呓语病（L68）】`它的语气永远自信,从来不说「我不确定」` → `它常常连不确定的时候也说得很肯定，所以不能只听语气。`。理由：“永远、从来不”与现实工具有时会表达不确定相矛盾，也削弱“查证而非背绝对结论”的课程口径。
- 【lesson-3.html·下令术三段式（L30、L81、L106）】`说什么+什么要求+做什么用`；示例`给一年级小朋友讲三个霸王龙的有趣知识,要简短` → 统一口径为`任务＋要求＋用途/对象`，示例改成`请讲三个霸王龙知识；每条一句话；讲给一年级小朋友听。`。理由：当前定义和示例的三段对应不直观，孩子难以迁移到第 5 章。
- 【lesson-3.html·下令术（L81）】`三段齐,使魔就乖;缺一段它就猜,一猜呓语病又犯` → `三段说清楚，使魔就更不容易猜歪；但答案仍要用鉴言术查一查。`。理由：原句暗示“好 prompt 能消除呓语病”，与本章核心“任何使魔都可能说错”冲突。
- 【lesson-3.html·抓错大赛（L112）】`没受过毛球的训练,呓语病更重` → `这是一只陌生的野生使魔；无论陌生使魔还是毛球，都可能犯呓语病。`。理由：通用 AI 并非因为“没受过毛球训练”才更会编，后文也明确毛球同样会错。
- 【lesson-3.html·授章（L133）】`图鉴真身(齐诵)+ English:prompt · fact-check` → 在本页实际写出五章统一的完整“图鉴真身”齐诵词，再另列英语词。理由：本页只有指令标签，没有可齐诵的正文，与第 1 章“每章一次”的承诺不一致。
- 【lesson-3.html·家长卡（L145—146）】孩子任务`用 AI 学 3 个新知识来教您`；家长步骤`问完挑一条一起查证` → `孩子先学 3 个知识点，再从中挑至少 1 条与家长一起查证，最后才教给家长。`。理由：把“查证”明确嵌入作业闭环，避免任务只剩“问 AI、复述 AI”。

- 【lesson-4.html·监工操（L89）】`收尾:热身完毕——下半场,见真的` → `收尾：热身完毕——下半场，真家伙登场！`。理由：“见真的”残缺且不够响亮，改写更像转场口号。
- 【lesson-4.html·三把钥匙①（L104）】`使魔的温柔话就像售货机播放:字是对的、声音是暖的,后面没有一颗心。` → `使魔说起安慰话，像售货机亮起一句“祝您开心”：听着暖暖的，却不是一颗心在里面感受。`。理由：原句偏抽象，改写保留售货机比喻并把“没有心”讲得柔和。
- 【lesson-4.html·五条路线（L125—129）】`敢说话的火苗,越大声越强。`；`迅捷如风,越战越勇。`；`只有最爱探索的孩子才能唤醒。` → `炎语者：敢把故事说出口，声音越有力量，火苗越亮。`；`风刃使：一眼分清不同物品，出手快得像风。`；`神秘支：想走一条没人走过的路？这张卡正在等你。`。理由：原文有喊得越大声越好、路线能力与项目不匹配、给孩子排高低等问题，改写让三条路线都对应实际任务。
- 【lesson-4.html·章节预告（L156）】`成体若要抵达完全体——金色的那个形态——只差一场真正的战斗。` → `成体想披上金辉、抵达完全体，只差最后一场战斗。明天，家长会来观战——你敢带着自己的路线出战吗？`。理由：压缩解释性插语，用“披上金辉”和挑战问句拉高终章期待。

### 3. 一致性与教学口径

- 【lesson-4.html·三把钥匙②（L105）】`三个不告诉`下列出`真名字、学校和住址、密码` → 明确成`三类不告诉：①身份和地点（真名、学校、住址）；②账号密码；③只和信任的大人说的悄悄话。`。理由：当前标题说“三个”，正文表面却列出四项，孩子难以复述，后续咒语又漏掉“学校”。
- 【lesson-4.html·三把钥匙②（L105）】`只跟妈妈说的悄悄话不说` → `只跟家里信任的大人说的悄悄话，不告诉 AI`。理由：课程其他位置使用“爸爸妈妈、家人、大人”，此处只写“妈妈”会排除其他照护结构。
- 【lesson-4.html·三把钥匙③（L106）】`这个权力叫终审权——从今天起是你们的,谁也不能替你们用。` → `这个权力叫终审权——从今天起，你要学会自己检查；重要决定还要和家里信任的大人一起点头。`。理由：“谁也不能替你们”与本章“家长共签、成人监督”的安全口径冲突，也不符合 6—8 岁儿童的责任边界。
- 【lesson-4.html·契约（L114）】`爸爸妈妈知道(最好就在旁边)` → `家里信任的大人知道，并尽量陪在旁边`。理由：称呼应覆盖父母以外的监护人，并与本章“找真人/找大人”统一。
- 【lesson-4.html·五条路线（L127）】`分类小发明 · 调到百发百中` → `分类小发明·多测几次，调得更稳`。理由：“百发百中”与前两章反复强调“AI 会认错”正面冲突，第 5 章也要求孩子说明它何时会错。
- 【lesson-4.html·五条路线活动说明（L131）】`盘点白板上各自的天赋星星` → 若前三章没有实际记录“天赋星星”，改为`回想前三章：你最喜欢讲故事、唱歌、分类、出题，还是自己发明？`；若确有线下记录，则在教师底牌补明来源。理由：当前五份 HTML 中没有建立“天赋星星”的可见机制，本章突然盘点会造成剧情断层。
- 【lesson-4.html·授章+预告（L155）】`图鉴真身(齐诵)+ English:agent · plan · check` → 写出统一齐诵词，并把栏目名改为`英语：agent · plan · check`。理由：第 3、4 章都只写“齐诵”指令而无正文，教师无法保证五章口径一致。
- 【lesson-4.html·家长卡（L162）】`重要动作它必须先问人`与正文`先回来问老板` → 统一为`重要动作必须先停下来，问孩子和在场大人`。理由：“老板”在剧情中指孩子，“人”又可能指任何人，两者责任主体不一致。
- 【lesson-4.html·家长到场预告（L156、L163）】`家长会到场观战`；`明天毕业展需您到场最后 20 分钟` → 与第 5 章时间轴统一后，明确写成同一个到场时段，例如`请在课程第 65 分钟前到场，参与最后 25 分钟`。理由：第 5 章家长环节实际从 65 分钟持续到 90 分钟，共 25 分钟，不是 20 分钟。

## 第 5 章：出战章·最终试炼

### 1. 文法与用字

- 【lesson-5.html·封面及全章】`90 分钟(含中场 10')`；`通关三条件全过`；`完全体(金辉)` → `90 分钟（含 10 分钟中场休息）`；`三项通关条件全部达成`；`完全体（金辉）`。理由：前者延续半角标点问题，“通关三条件全过”则有明显词序错误。
- 【lesson-5.html·封面（L23）】`毛球在全场见证下抵达完全体` → `毛球在全场的见证下进化为完全体`。理由：“在全场见证下”缺结构助词，“抵达形态”也不如“进化为形态”自然。
- 【lesson-5.html·老师底牌（L31）】`班级>8 人毕业展改"走展"` → `班级超过 8 人时，毕业展改为“走展”`。理由：面向教师的可见文案也不宜直接使用代码式比较符和半角引号。
- 【lesson-5.html·副本攻坚（L49）】`用《小星星》调子写 4 句毛球歌词` → `用《小星星》的调子写 4 句关于毛球的歌词`。理由：原句缺少两个结构助词，口语虽能猜懂但不够规范。
- 【lesson-5.html·副本攻坚（L50）】`展示=表演+讲"我怎么训练的、它何时会错"` → `展示＝现场表演＋讲清楚“我是怎么训练的，它什么时候会错”`。理由：等号两边需要同类结构，“讲”后的两个分句也应补齐主语。
- 【lesson-5.html·副本攻坚（L52）】`尺度老师把关` → `题目范围和安全边界由老师确认`。理由：“尺度把关”含义模糊且偏成人项目行话。
- 【lesson-5.html·中场布展（L60）】`作品上展示桌/贴墙` → `把作品摆上展示桌或贴到墙上`。理由：原句漏掉处置动词，斜杠也不适合直接朗读。
- 【lesson-5.html·出战演练（L74）】`大家好,这是我的 project《____》。` → `大家好，这是我的作品（project）——《____》。`。理由：中文句中直接插入英文名词不够自然，首次对应后再进入英文展示更顺。
- 【lesson-5.html·出战演练（L74）】`我让它改成了/我把它改成了____。` → `我请它把____改成了____。`或`我自己把____改成了____。`。理由：斜杠模板无法直接说出口，而且原句缺少“把什么改成什么”的双宾项。
- 【lesson-5.html·出战演练（L75）】`两人一组互相排一遍。` → `两人一组，互相排练一遍。`。理由：“排一遍”缺少中心动词，容易被理解为排队。
- 【lesson-5.html·毕业展（L81）】`孩子守作品旁讲给走到面前的家长` → `孩子守在作品旁，讲给来到展位前的家长听`。理由：原句缺介词“在”和补语“听”，语序也较拗口。
- 【lesson-5.html·授勋（L111）】`知道自己永远是终审和拍板的那个人` → `知道自己要做最后检查，并和大人一起拍板`。理由：“是终审的人”搭配不当，且儿童并非所有事项的唯一最终决策者。
- 【lesson-5.html·家长卡（L128）】`五路线轮着玩`；`时长条款让孩子重新谈判` → `五条路线轮着体验`；`每学期和孩子重新商量使用时长`。理由：前者缺量词，后者法律/商业色彩过重，不像家庭教育话术。
- 【lesson-5.html·完全体动态文案（L147）】`完全体 ·「焰歌咏主」Spark Cantor!` → `完全体·“焰歌咏主” / Spark Cantor！`（其他路线同样处理）。理由：中文称号和英文称号之间缺少分隔，且引号、感叹号制式混乱。

### 2. 生动度（重点）

- 【lesson-5.html·封面（L23）】`本章没有新知识——它是前四章全部本领的一次真实合战。` → `今天不学新招——前四章练过的所有本领，全部带上战场！这是你和毛球的总决战。`。理由：“真实合战”书面且略带日式表达，改写更像儿童冒险收官口号。
- 【lesson-5.html·副本开门（L39）】`毕业副本 · 通关三条件……` → `毕业副本开门！三盏通关灯：第一盏，作品做完；第二盏，老板终审通过；第三盏，抓到并改掉至少一处使魔的错。三盏全亮，才能通关！`。理由：把三条规则变成“三盏灯”，既可视化又便于现场逐项确认。
- 【lesson-5.html·誓师（L40）】`五天前,你们连它是什么都说不上来。今天,你们是持证驯养师……` → `第一章刚开始时，你们还说不清蛋里是谁。现在，四枚徽章已经在手，成体毛球就在身边。全体起立——最后一次誓师！`。理由：避免时间错误和提前“持证”，同时用徽章数量制造收官感。
- 【lesson-5.html·副本攻坚巡场（L54）】`暗线:下单不清→三段式;它编知识→查一查;做完没看→监工三问;想交差→"终审了吗?"` → `老师巡场四连问：命令说清楚了吗？知识查过了吗？作品从头看过了吗？最后——导演，你终审了吗？`。理由：“暗线”和箭头链像内部策划笔记，四连问更适合教师直接使用。
- 【lesson-5.html·终审仪式（L66）】`给自己的作品挑出一个可改进点,当场改掉` → `拿出侦探眼，揪出作品里一个“还能更好”的地方——现在就把它改掉！`。理由：“可改进点”偏成人职场语言，改写与鉴言术、慧眼的冒险语汇连起来。
- 【lesson-5.html·终审结语（L68）】`这件事,很多大人一辈子都没做到过。` → `这一步，连很多大人都会忘记；可你们今天一个也没漏掉。`。理由：原句夸张失真且有贬低大人的意味，改写仍能给孩子成就感。
- 【lesson-5.html·出战演练（L75）】`谁的错抓得漂亮,谁掌声最响。` → `谁抓得准、改得妙，谁就赢得最响的掌声！`。理由：“谁的错”可能被听成孩子自己的错误，改写更清楚也更有两拍节奏。
- 【lesson-5.html·收官毛球话术（L120）】`Ⅱ期,项目工坊,选一个你真正想做的东西,指挥我,把它做出来。想好了吗?到时候见。` → `下一次，项目工坊的大门会打开。选一个你真正想做的东西，带着目标来指挥我——新的副本里见！`。理由：原句像续班通知，改写保持产品信息但用剧情语言收尾。

### 3. 一致性与时间轴

- 【lesson-5.html·封面/家长时段（L19、L80—121）】`家长最后 20 分钟观战`；实际家长观战从`65-80'`开始，之后还有`80-85'`授勋和`85-90'`收官 → 二选一统一：要么封面改为`家长参与最后 25 分钟`，要么把家长入场/毕业展起点调整到第 70 分钟。理由：现有时间轴中家长相关环节共 25 分钟，和第 4 章家长卡的“最后 20 分钟”不一致。
- 【lesson-5.html·誓师（L40）】`五天前,你们连它是什么都说不上来。` → `第一章刚开始时，你们还说不清它是什么。`；若课程确定连续五天，也可写`四天前`。理由：第 5 天回看第 1 天是“四天前”，且课程未必按连续五天开设，用章节锚点最稳。
- 【lesson-5.html·誓师/授勋（L40、L110）】开场称孩子为`持证驯养师`，结尾才授予`认证小驯养师` → 开场改为`四章在手的准驯养师`或`即将毕业的驯养师`。理由：认证在 80 分钟后才发生，开场“持证”会让终场授勋失去逻辑。
- 【lesson-5.html·炎语者任务（L48）】`三段式下单(主角+样子+发生什么)` → `故事专用三格单（主角＋样子＋发生什么），并说明它是第 3 章“任务＋要求＋用途/对象”的故事版。`。理由：否则孩子会以为“下令术三段式”突然换了定义。
- 【lesson-5.html·风刃使任务（L50）】`调到可靠` → `多测几轮，调得更稳，并记录它什么时候会错`。理由：与第 4 章“百发百中”同属过度承诺，和本页展示要求“它何时会错”也不够衔接。
- 【lesson-5.html·三句祝福咒（L83—85）】`真名地址和密码,AI 再好也不说!` → `真名、学校、住址和密码，AI 再好也不说！`，或按第 4 章统一后的“三类秘密”重写整句。理由：本句漏掉契约中的“学校”，安全口诀不能越背越少。
- 【lesson-5.html·授勋家长结语（L111）】`孩子们学会的不是让 AI 替自己做事` → `孩子们学会的，不是把事情一股脑儿丢给 AI`。理由：第 4—5 章正是在教 agent 协助完成任务，原句否定了前面的课程实践；真正要反对的是失去目标、监工与终审。
- 【lesson-5.html·最后一次图鉴问答（L118—119）】`人造的、会学习的电脑程序!没有心!` → 使用五章统一完整齐诵词，不在终章临时缩成两句。理由：终章正是记忆回收点，应完整复现而不是删掉“不是小动物、不是魔法”等关键锚点。
- 【lesson-5.html·收官毛球话术（L120）】`完全体不是终点——是出战资格。` → `完全体不是终点——是开启更大项目的资格。`或`完全体不是终点——是下一场冒险的起点。`。理由：毛球刚通过“出战日”的真正战斗才进化为完全体，进化后又获得“出战资格”会形成因果循环。
- 【lesson-5.html·授勋/收官/家长卡（L110、L120、L127）】`Ⅱ期「Agent 项目工坊」`；`Ⅱ期,项目工坊`；`Ⅱ期预告` → 统一为`第二阶段“Agent 项目工坊”`，首次写全称，后文简称`项目工坊`。理由：罗马数字、英文大写和简称三种口径并存，不利于家长快速识别同一项目。
- 【lesson-5.html·家长卡（L127）】`公开发布` → `在毕业展现场展示`。理由：本章只设计了班级/家长现场展示，没有提供公开上网发布的剧情、授权或隐私口径，“发布”会造成范围误解。

## 跨章统一项

- 【lesson-1.html～lesson-5.html·全部中文主句】半角`,` `:` `!` `?` `()` `""`与中文混排 → 中文语句统一使用`，` `：` `！` `？` `（）` `“”`，时间范围统一用`0—10 分钟`或`0–10′`中的一种。理由：这是五章最密集、最影响完成度的基础编辑问题，不能只零星修代表句。
- 【lesson-1.html～lesson-5.html·英语栏目】`Eng`、`English`、`English time`三种写法 → 统一为`英语`或`英语时间`；只保留本章目标词本身为英文。理由：栏目名称不是学习词，统一中文能减少无意义的中英夹杂。
- 【lesson-1.html～lesson-5.html·核心技术词】`AI / sensor / prompt / agent / plan / check / project` → 首次出现使用`中文解释（英文词）`，同一章后续优先用已设定的中文剧情称呼；`deck / bug / app`直接改中文。理由：保留真正的教学词，同时清理只服务制作团队的英文行话。
- 【lesson-1.html～lesson-5.html·图鉴真身】五章版本长短不一，且前两章共有`它没有小动物`病句 → 五章逐字统一为：`使魔的真身，是人造的、会学习的电脑程序。它不是小动物，不是魔法，也没有一颗心。知道真身，还能演好戏——才是高级驯养师。`。理由：这是全课程最重要的反拟人化记忆锚点，必须稳定重复。
- 【lesson-3.html～lesson-5.html·鉴言术口诀】`先想→再问→查一查`、`先想后问`、`下单→查一查`交替出现 → 教学主口令固定为`先想·再问·查一查`；进入 agent 项目后再说明`“再问”也叫“下单”`。理由：同一技能不应随章节换词，否则低龄儿童难以形成条件反射。
- 【lesson-4.html～lesson-5.html·儿童安全责任】`老板自己终审、谁也不能替`与`家长在旁、共签契约`并存 → 统一为`孩子负责先想、提问和检查；涉及账号、隐私、花钱、发送或发布时，由孩子和在场大人一起拍板。`。理由：既保留“我是老板”的主体感，又不把成人责任转嫁给 6—8 岁儿童。

## 总评

### 整体水平

整体处于**有鲜明世界观、可直接排课，但尚未达到出版级/正式投影级定稿**的水平。五章主线完整，蛋→幼体→开口→成体→完全体的成长节奏清楚；“三关试炼、星光网、两门功夫、三把钥匙、毕业副本”等教学隐喻也有较强记忆点。最有价值的是课程没有把 AI 写成全知伙伴，而是持续要求孩子训练、查证、监工和终审。

当前主要短板不在创意，而在最后一轮编辑收口：基础标点仍像草稿；一些页面写成教师策划摘要而不是可说、可演的话；少数设定和时间轴互相打架，其中“只吃水果/只吃例子”“五天前”“最后 20/25 分钟”“完全体后才获出战资格”属于必须优先修正的硬伤。

### 最大的三个共性问题

1. **中文制式未统一。** 五章普遍使用半角逗号、冒号、括号、问号、感叹号和英文直引号，`English / Eng / English time`、`agent / Agent`也未统一，明显拉低成品感。
2. **说明性强，现场语言感不足。** 封面、活动规则和部分教师话术经常一次塞进四五个概念，缺少短句、停顿、拟声词、动作和可供全班回应的节拍；最有效的改法不是加形容词，而是把“摘要”改成“正在发生的镜头”。
3. **关键口径没有锁死。** 图鉴真身、鉴言术三步、三个不告诉、家长参与时段、儿童与成人的拍板边界，以及成体/完全体/出战的因果关系，在不同章节出现删减或改名，削弱了养成剧情最需要的重复记忆。

### 最值得全局替换的表达

| 现有表达 | 建议统一表达 | 适用说明 |
|---|---|---|
| `它没有小动物` | `它不是小动物` | 明确病句，五章齐诵词统一修正 |
| `发现得了、修得回来` | `能发现，也能改回来` | 适用于教师目标、事故善后、家长卡 |
| `使魔会学坏/被教坏/被带坏` | `使魔会学错/被错误例子教错` | 避免把数据错误道德化 |
| `使魔很聪明` | `使魔很能干，但不一定可靠` | 防止“聪明＝正确”的儿童误读 |
| `先想后问` | `先想·再问·查一查` | 固定为鉴言术主口诀；agent 场景再解释“问＝下单” |
| `百发百中/永远不出错/从来不说不确定` | `更稳/可能出错/常常说得很肯定` | 清理与课程核心相冲突的绝对化表达 |
| `可改进点` | `一个“还能更好”的地方` | 更适合 6—8 岁儿童口语 |
| `公开发布` | `在毕业展现场展示` | 与现有活动范围和隐私口径一致 |
| `deck / bug / app` | `幻灯片 / 兼容问题 / 应用` | 非教学词一律中文化 |
| 半角中文标点 | 全角中文标点 | 五章一次性全局统一 |

### 建议修订优先级

- **P0（先修硬伤）：** 图鉴真身病句及五章统一；第 1 章“只吃水果”与第 2 章冲突；第 3 章袋鼠纠错例的事实风险；第 4—5 章家长 20/25 分钟；第 5 章“五天前”“持证驯养师”“完全体后才获出战资格”。
- **P1（再修儿童口语）：** 每章优先采用本报告“生动度”中的 5—8 处改写，尤其是封面、剧情开场、核心仪式和章节预告。
- **P2（最后做制式清理）：** 全角标点、栏目名、英文术语首次释义、数字范围、引号及动态按钮文案统一。
